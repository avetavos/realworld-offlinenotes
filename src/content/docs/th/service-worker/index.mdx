เพิ่ม Service Worker ที่ precache app shell และ asset เพื่อให้ OfflineNotes ทำงานได้โดยไม่มี network และ install เป็น PWA

บทเรียนของ module นี้กำลังจะมา — ติดตามที่แถบด้านข้างเมื่อมันทยอยลง
