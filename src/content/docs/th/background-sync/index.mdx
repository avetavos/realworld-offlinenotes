  order: 0
---

ใช้ Background Sync API เพื่อให้ edit ที่ทำ offline sync เองทันทีที่ connectivity กลับมา — ไม่ต้อง retry เอง

บทเรียนของ module นี้กำลังจะมา — ติดตามที่แถบด้านข้างเมื่อมันทยอยลง
