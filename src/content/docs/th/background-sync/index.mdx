ใช้ Background Sync API เพื่อให้ edit ที่ทำ offline sync เองทันทีที่ connectivity กลับมา — ไม่ต้อง retry เอง

เริ่มที่ [Deferring sync while offline →](/offlinenotes/th/background-sync/deferring-sync/) แล้วไล่เรียนบทเรียนตามลำดับ (ดูที่แถบด้านข้าง)
